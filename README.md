# Maison Flamingo · site

Site vitrine de maisonflamingo.fr : HTML, CSS et JavaScript natifs, sans étape de construction.

- `index.html` : la page, `style.css` : la charte sunset, `site.js` : navigation et liste d'attente.
- Après chaque modification d'un fichier CSS ou JS, monter le numéro `?v=` dans les deux pages, sinon les navigateurs servent l'ancien.
- Le formulaire part par courriel vers contact@maisonflamingo.fr tant que `ADRESSE_FORMULAIRE` est vide dans `site.js`.
- Prévisualisation locale : `python3 -m http.server 8791`.
